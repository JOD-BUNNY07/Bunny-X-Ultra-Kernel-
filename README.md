<h1 align="center">HyperFusionX Kernel</h1>

> **Power. Efficiency. Control.** Unleash the full potential of your Realme 6 Pro.

**HyperFusionX** is a custom Linux kernel for the Realme 6 Pro, based on the official realme kernel. Built with a focus on performance, battery life, and stability, HyperFusionX aims to deliver a refined and efficient kernel experience for enthusiasts and everyday users alike.

## 🚀 Features

| Category | Highlights |
| :--- | :--- |
| **⚙️ Core** | Based on Linux 4.14.336 • Official realme-sm7125 source |
| **🧬 Compatibility** | Android 13, 14, 15 & 16 (AOSP & ROMs) |
| **🎯 Performance** | Optimized CPU/GPU scheduling • Reduced overhead • Smoother UI |
| **🔋 Battery** | Intelligent power management • Aggressive doze modes • Efficient frequency scaling |
| **❄️ Thermal** | Enhanced thermal control for sustained performance |
| **🛠️ Extras** | **KernelSU-Next** • **SUSFS** • F2FS Compression • WireGuard VPN • exFAT support |

## 📱 Supported Devices

- Realme 6 Pro (RMX2061)
- Realme 6 Pro (RMX2063)

## ❓ FAQ & Support

**Q: Will this work on my Custom ROM?**

**A:** Yes, it's designed to be compatible with most AOSP-based ROMs for the Realme 6 Pro.

**Q: What is KernelSU?**

**A:** It's a root solution that allows granting root permissions on a per-app basis directly from the kernel. The "Next" version is the modern iteration.
